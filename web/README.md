# CQA Freedom Broker — Web Interface (`web/`)

Зона ответственности: **Надир (`nadir/web`, папка `web/`)**

## Что реализовано

1. **Чистый стек без сборки (Zero-build)**:
   - Чистый HTML5, CSS3 и ванильный JavaScript (ES6+).
   - Запускается напрямую в любом браузере двойным кликом по `index.html` или через любой статический веб-сервер.
   - Полностью готов к адаптации и встраиванию как HTML-компонент в **Dynamics 365**.

2. **Экран 1: Диалоги и оценка (Main Workspace)**:
   - **Список диалогов (Sidebar)**:
     - Фильтрация по типам каналов: Все / 💬 Чаты (agent chat) / 📞 Звонки (voice call).
     - Фильтрация по языкам: Все / RU / KZ / EN.
     - Фильтрация по статусам: С грубыми ошибками (Gross Error) / На апелляции (Appeals).
     - Поиск по ID диалога или фрагментам текста.
   - **Интерактивный транскрипт**:
     - **Каждая реплика имеет явный порядковый номер (`#0`, `#1`, `#2`, ...)** в соответствии с контрактом `message_index` из `AGENTS.md`.
     - Роли четко разделены по стилям: Клиент (Client), Оператор Freedom (Operator), AIM Бот (Bot), Служебные события (System).
     - Для голосовых звонков (`voice call`): встроенный аудиоплеер с управлением скоростью (0.75x–2.0x), шкалой перемотки и кнопкой быстрого перехода к записи в Dynamics 365.
   - **Карточка оценки CQA**:
     - Крупный итоговый балл (0.00–100.00) с динамическим цветовым статусом.
     - Баннер критических нарушений (Грубые ошибки: предложение услуг в обход, оскорбления, утечка данных).
     - Прогресс-бары баллов по секциям: «Начало и понимание запроса», «Безопасность и решение», «Ведение и завершение диалога».
     - Полная детализация по каждому из 8 критериев чек-листа:
       - Ответ (Да / Нет / Шкала / N/A), базовый вес и **эффективный вес с перераспределением при N/A**.
       - Заработанные баллы за критерий.
       - Человекочитаемое объяснение (Explanation).
       - Обоснование неприменимости (при N/A).
       - **Интерактивная кнопка-ссылка на реплику-доказательство (`[📍 Перейти к реплике #X ↗]`)**: при клике транскрипт плавно скроллится к реплике с яркой пульсирующей изумрудной подсветкой!

3. **Экран 2: Центр апелляций (QC Appeals Review)**:
   - Просмотр всех поданных операторами обращений.
   - Модальное окно принятия решения проверяющим (QC Supervisor):
     - Подтвердить исходную оценку ИИ или изменить оценку (Да/Нет/N/A/Шкала).
     - Обязательное обоснование решения.
     - Моментальный пересчет итогового балла диалога по математике `scoring.py`!

4. **Экран 3: Конструктор чек-листа (Checklist Configurator)**:
   - Просмотр, добавление, редактирование и удаление критериев чек-листа.
   - Настройка весов, типов (да/нет, шкала, флаг), доступности N/A и инструкций.
   - Кнопка **«Применить к диалогам и пересчитать»** — решает ключевую задачу хакатона на 23-м часу («организаторы предложат заменить один критерий через интерфейс»).
   - Кнопка сброса к заводскому стандарту Freedom Broker.

5. **Экран 4: Сводная аналитика и экспорт отчетов (Executive QA Dashboard)**:
   - Обзорные KPI-метрики для руководства: средний CQA индекс качества, покрытие аудитом, инциденты комплаенс, индекс апелляций.
   - Визуальное распределение диалогов по уровням качества (Отлично, Хорошо, Зона внимания, Грубые ошибки).
   - Таблица compliance-рейтинга по всем 8 критериям регламента Freedom Broker.
   - Кнопка **«Экспорт отчета в CSV»** для автоматической выгрузки реестра проверок.
   - Кнопка **«Экспорт в JSON»** для обмена данными с внешними BI-системами.

6. **Соответствие правилам хакатона и AGENTS.md**:
   - Строго внутри `web/`.
   - Ветка `nadir/web`.
   - Никаких захардкоженных в коде критериев.
   - Все расчеты баллов соответствуют логике `src/cqa/scoring.py`.
   - Работает автономно на тестовых данных из `mock_data.js` / `mock_data.json` и автоматически подключается к FastAPI бэкенду Алихана, когда сервер запущен на `/api/...`.

## Как запустить

### Вариант 1: Прямое открытие в браузере
Просто откройте файл `web/index.html` в любом современном веб-браузере (Chrome, Safari, Edge, Firefox).

### Вариант 2: Локальный веб-сервер
Из корневой папки репозитория:
```bash
python3 -m http.server 3000
```
И откройте в браузере: `http://localhost:3000/web/`
